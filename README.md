# 📦 Termux Packages Collection

A curated collection of useful **Termux packages**, tools, and utilities — made for Android power users, ethical hackers, and command-line lovers. Install and use everything directly from Termux!

---

## ⚙️ How to Use

1. Install [Termux](https://f-droid.org/packages/com.termux/) from F-Droid (recommended).
2. Clone this repository:
   ```bash
   git clone https://github.com/ganuchavan8491/Ternux_pkgs.git
   cd Ternux_pkgs
   ```

3. Run the installer or use packages manually:
   ```bash
   bash setup.sh
   ```

> Make sure to give storage permission:
```bash
termux-setup-storage
```
